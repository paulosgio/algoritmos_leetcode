# 🧠 Algoritmos e Estruturas de Dados

Repositório criado para praticar **algoritmos e estruturas de dados** utilizando TypeScript, com exercícios baseados principalmente em problemas do LeetCode.

## 📚 Conteúdos

- Binary Search
- Bubble Sort
- Sliding Window
- Two Sum
- Contains Duplicate
- Reverse Words
- Linked Lists
  - Singly Linked List
  - Doubly Linked List
  - Merge Linked List
  - Reverse Linked List
  - Palindrome Linked List
  - Middle of Linked List
- Intersection of Two Arrays
- First Unique Character
- Exponential Search

## 🎯 Objetivo

Praticar resolução de problemas, estruturas de dados, análise de complexidade e desenvolvimento do raciocínio algorítmico.

## 🛠️ Tecnologias

- TypeScript
- Node.js
